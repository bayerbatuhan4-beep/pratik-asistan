# Pratik Asistan

Günlük işlemleri, hesaplamaları ve hızlı araçları tek bir sade arayüzde toplayan pratik web uygulaması.

## Canlı Yayın Linkleri
- **Cloudflare Workers (Birincil):** https://pratik-asistan.bayerbatuhan4.workers.dev/
- **Vercel (Yedek):** https://pratik-asistan.vercel.app/

## Özellikler
- **Hızlı ve Hafif Arayüz:** Harici ağır kütüphanelere ihtiyaç duymadan saf HTML, CSS ve JavaScript ile anında açılır.
- **Kesintisiz Erişim:** Cloudflare Workers altyapısı sayesinde hem mobil veride hem de tüm Wi-Fi ağlarında yüksek hızda çalışır.
- **Responsive Tasarım:** Masaüstü ve mobil cihazlarla tam uyumludur.

## Teknolojiler
- HTML5 / CSS3 / Vanilla JavaScript
- Cloudflare Workers (Static Assets)
